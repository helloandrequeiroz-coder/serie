# #VemMonstro — app de treino

Web app (PWA) de treino: planos por dia, combinados, pirâmides/drop sets, cronômetro de descanso, histórico e progresso. Login e dados por pessoa via Supabase.

- App: https://helloandrequeiroz-coder.github.io/serie/
- Banco: `supabase.sql` (rodar uma vez no SQL Editor do Supabase)
- Imagens dos exercícios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (domínio público)
